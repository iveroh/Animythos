# UI

This folder contains reusable interface components used by the Animythos website.

These components belong to the documentation and showcase website and are not part of the Three.js component library.

Examples:

ui/
├── Navbar.tsx
├── Sidebar.tsx
├── ComponentCard.tsx
├── DemoContainer.tsx
├── CodeBlock.tsx
└── PropsTable.tsx

UI components can be used across multiple pages.

Examples include:

- Navigation
- Buttons
- Cards
- Code displays
- Tabs
- Layout containers
- Documentation elements

Three.js effects and animations should not be placed here. Those belong in `src/components`.
